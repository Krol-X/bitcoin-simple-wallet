# BitcoinSimpleWallet

A minimal Bitcoin signet wallet for the command line, with one-shot commands and an interactive mode.
Generates a key, shows the address and balance, builds and broadcasts
P2WPKH transactions via the mempool.space API.

> 🚧 **v2 is under construction.**
> The working version is tagged [`v1.0`](https://github.com/Krol-X/bitcoin-simple-wallet/tree/v1.0).
